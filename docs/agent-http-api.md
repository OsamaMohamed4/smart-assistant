# منصة مسار — واجهة الـ Agent البرمجية (Agent HTTP API)

واجهة من خادم إلى خادم: يرسل نظامكم استفسار العميل، ويستلم رد الـ AI Agent الخاص بالشركة نصاً جاهزاً للعرض. يعمل الرد على نفس سيناريو الشركة ونفس قاعدة المعرفة التي يستخدمها الوكيل في المكالمات.

---

## 1) نقطة النهاية

```
POST https://sermad.up.railway.app/api/v1/agent/chat
Content-Type: application/json
```

الرد متزامن: يعود الرد في نفس الطلب، ومتوسط الزمن من ثانية إلى ثلاث ثوانٍ.

---

## 2) المصادقة

لكل شركة مفتاح خاص يبدأ بـ `sa_`. يُصدره مسؤول منصة مسار من «الشركات» ← ⋯ ← «مفاتيح API»، ويظهر **مرة واحدة فقط** عند إنشائه، ويُسلَّم لكم عبر قناة آمنة منفصلة، لا في هذا المستند.

```
Authorization: Bearer sa_xxxxxxxxxxxxxxxx
```

أو بديلاً:

```
X-Api-Key: sa_xxxxxxxxxxxxxxxx
```

- المفتاح **مقيّد بشركة واحدة**: هو الذي يحدد الشركة، ولا يمكن استخدامه للوصول إلى شركة أخرى.
- **يُستدعى من خادمكم فقط.** لا يوضع المفتاح في كود المتصفح أو تطبيق الجوال، لأن أي زائر يستطيع قراءته من هناك.
- يمكن إيقاف المفتاح من نفس الشاشة، فيتوقف فوراً. ولتغييره: أنشئوا مفتاحاً جديداً، ثم أوقفوا القديم.

---

## 3) الطلب (Request Body)

| الحقل | النوع | إلزامي | الوصف |
|---|---|---|---|
| `customer_phone` | string | ✅ | رقم جوال العميل، ويفضّل بصيغة دولية مثل `+966501234567`. هو مفتاح المحادثة: كل رقم له محادثته الخاصة. يُرفض أي معرّف ليس رقم هاتف (كود عميل، بريد إلكتروني)، وأقل عدد مقبول من الأرقام ٨. |
| `message` | string | ✅ | نص رسالة العميل. الحد الأقصى ٤٠٠٠ حرف. |
| `variables` | object | ⬜ | قيم تُعوَّض في نص السيناريو، مثل `{{customer_name}}`. الأسماء حروف إنجليزية وأرقام و`_`، والقيم نصوص أو أرقام حتى ٢٠٠ حرف. |
| `company_id` | string | ⬜ | غير مطلوب، لأن المفتاح يحدد الشركة. إن أُرسل يجب أن يطابق شركة المفتاح، وإلا يُرفض الطلب بـ 403. |

### مثال

```json
{
  "customer_phone": "+966501234567",
  "message": "السلام عليكم، متى موعد تسليم الوحدة؟",
  "variables": {
    "customer_name": "أحمد",
    "order_no": "4512"
  }
}
```

## 4) الاستجابة

### نجاح — HTTP 200

```json
{
  "success": true,
  "reply": "وعليكم السلام أستاذ أحمد، حياك الله. كيف أقدر أخدمك؟",
  "chat_id": "api-966501234567",
  "company_id": "co-xxxxxx",
  "latency_ms": 1240
}
```

| الحقل | الوصف |
|---|---|
| `success` | `true` عند نجاح المعالجة. |
| `reply` | نص الرد الذي يُعرض للعميل. |
| `chat_id` | معرّف المحادثة لدينا. لا يلزم تخزينه، فالمحادثة تُعرف من `customer_phone`. أرفقوه عند الإبلاغ عن مشكلة. |
| `company_id` | الشركة التي ردّت. |
| `latency_ms` | زمن المعالجة بالميلي ثانية. |

### الأخطاء

| الكود | السبب | ماذا تفعلون |
|---|---|---|
| **400** | حقل ناقص أو غير صالح (مثل `customer_phone` ليس رقم هاتف) | صحّحوا الطلب، ولا تعيدوه كما هو. |
| **401** | المفتاح مفقود أو غير صحيح أو موقوف | راجعوا ترويسة المصادقة. |
| **403** | `company_id` لا يطابق شركة المفتاح | احذفوا `company_id` أو صحّحوه. |
| **404** | الشركة غير موجودة | أبلغونا. |
| **409** | لا يوجد سيناريو مفعّل للشركة | أبلغونا، فالتفعيل من جانبنا. |
| **413** | الرسالة أطول من ٤٠٠٠ حرف | اختصروا الرسالة. |
| **429** | تجاوز حد الطلبات: ١٢٠ طلباً في الدقيقة لكل مفتاح، أو الحد اليومي لرسائل الشركة (الافتراضي ٢٠٠٠ رسالة يومياً، ويُعدّل بالاتفاق) | انتظروا ثم أعيدوا المحاولة. |
| **502** | تعذّر الحصول على رد من محرك الذكاء الاصطناعي | أعيدوا المحاولة مرة واحدة بعد ثانيتين. |

شكل رسالة الخطأ:

```json
{ "success": false, "error": "invalid api key" }
```

وأخطاء التحقق من الحقول (400) تأتي بالتفصيل:

```json
{
  "error": "validation failed",
  "details": [
    { "path": "customer_phone", "message": "customer_phone must be a phone number, e.g. +966501234567" }
  ]
}
```

## 5) استمرارية المحادثة

- المحادثة تُحفظ لكل عميل حسب `customer_phone`، وتُبنى من آخر ٢٠ رسالة.
- لا تنتهي بمرور الوقت: العميل الذي يعود بعد أيام يكمل من حيث توقّف.
- أرسلوا الرقم **بنفس الصيغة دائماً**. `+966501234567` و`0501234567` تُعدّان محادثتين مختلفتين، والصيغة الدولية هي الموصى بها.
- كل المحادثات تظهر في لوحة منصة مسار ضمن «المحادثات».

## 7) قواعد التشغيل

1. **المهلة (Timeout):** ٣٠ ثانية من جانبكم.
2. **إعادة المحاولة:** عند 502 أو 429 فقط، مرة واحدة بعد ثانيتين. لا تُعاد طلبات 400 و401 و403 و404.
3. **الرسائل المتتابعة:** إذا أرسل العميل عدة رسائل خلال ثوانٍ، اجمعوها في رسالة واحدة لتجنّب ردود متفرقة.
4. **ما لا تدعمه الواجهة حالياً:** المرفقات والرسائل الصوتية (النص فقط)، والبث التدريجي للرد (Streaming)، وتحويل المحادثة لموظف.
